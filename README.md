# Colosseum

Learning playground for humanoid robots related to robot soccer,
built on top of [mjlab](https://github.com/neverorfrog/mjlab) (GPU-accelerated RL via MuJoCo Warp).

**Documentation:** https://neverorfrog.github.io/colosseum/

## Research Projects

| Project | Description |
|---------|-------------|
| [Dribbling](docs/research/dribbling.md) | Obstacle-avoidance dribbling with visual RMA |
| [Soccer Maze](docs/research/soccer-maze.md) | Goal-conditioned maze navigation to a ball |
